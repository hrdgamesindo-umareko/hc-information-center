# HC Information Center (frontend)

Portal informasi HC berbasis HTML, CSS, dan JavaScript murni. Data dari Google Apps Script.

- `index.html`: halaman utama
- `css/style.css`: tampilan
- `js/config.js`: alamat API (satu-satunya berkas yang diedit)
- `js/api.js`, `js/app.js`, `js/admin.js`: logika

Lihat `PANDUAN-INSTALASI.md`.
